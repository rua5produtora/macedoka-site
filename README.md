# Macedoka | Aviacao Executiva

Site institucional estatico criado para apresentacao comercial da Macedoka.

## Publicacao

Este projeto funciona diretamente no GitHub Pages, sem build.

1. Envie os arquivos para um repositorio GitHub.
2. Em `Settings > Pages`, selecione `Deploy from a branch`.
3. Escolha a branch `main` e a pasta `/root`.

## Estrutura

- `index.html`: conteudo do site
- `styles.css`: identidade visual e responsividade
- `script.js`: menu mobile e animacoes de entrada
